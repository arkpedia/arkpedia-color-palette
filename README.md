# Arkpedia color palettes

Community-maintained corrections for the [Arkpedia Color Palette Guesser](https://arkpedia.org/games/color-palette).

The generated catalog is in `palettes/generated-palettes.json`. If one of its five colors does not represent the operator artwork well, add a keyed entry to `palettes/community-overrides.json`. Arkpedia applies approved overrides on top of the generated catalog during its build.

This repository intentionally contains palette data rather than copies of operator artwork. Artwork previews are served by [`Arkpedia/arkpedia-skin-assets`](https://github.com/Arkpedia/arkpedia-skin-assets).

See [CONTRIBUTING.md](CONTRIBUTING.md) for the short correction workflow.
